# Contributing

Read AGENTS.md and the game direction. Discuss significant design changes in an issue and decision record. Keep changes small, include relevant behavioral verification, and explain player-visible effects. AI-assisted contributions are welcome; contributors remain responsible for correctness and provenance.

Run `./scripts/check.sh` before opening a pull request. Include actual test results and any unverified assumptions. Original contributions are submitted under the MIT license. Third-party assets must carry their own explicit compatible license and attribution.
