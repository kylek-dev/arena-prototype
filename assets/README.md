# Asset provenance

The public repository includes original procedural visuals and support for an optional third-party stock character. The browser spike generates its meshes and flat-color materials in crates/arena-client/src/lib.rs; the HUD lightning mark is an original inline SVG path in web/index.html. These code-authored prototype visuals are covered by the repository MIT license. No external reference imagery or asset generation service was used to create those procedural visuals. The optional downloaded character has separate provenance and licensing in [characters/README.md](characters/README.md) and is not included under MIT. Use original characters, silhouettes, iconography, sounds, and worldbuilding.

For every added asset record its path, creator/source URL, license, modifications, and attribution requirements. For AI-generated assets also record tool/model, date, prompt/reference provenance, and human edits when available. Do not claim exclusive rights from generation alone. Check provider terms before publishing generated assets. Never use protected game assets as source material.

Code and docs default to MIT; asset licensing must be explicit per contribution. Prefer CC0 or CC-BY-4.0 for external assets and keep notices alongside them. Decide a uniform license for original production assets before the art milestone.
