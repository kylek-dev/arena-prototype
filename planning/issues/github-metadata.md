Keep project management data reviewable and recoverable alongside source.

Acceptance criteria:
- Create a public GitHub Project linked to this repository when project-scoped authentication is available.
- Add initial issues and configure Todo/In Progress/Done views.
- Publish docs/wiki pages to the GitHub wiki, initializing the wiki in the UI if required.
- Export issue/project state into versioned planning data at milestones.
- Verify exports and wiki mirrors can be restored without an undocumented local dependency.

See docs/GITHUB.md for current publication status and recovery commands.
